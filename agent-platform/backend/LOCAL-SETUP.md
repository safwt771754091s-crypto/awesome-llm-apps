# تشغيل محلي على جهازك

## المتطلبات
- Docker Desktop أو Docker Engine مع Docker Compose.
- مفتاح مزود نموذج متوافق مع OpenAI API واسم النموذج. هذه النسخة تستعمل النموذج للتخطيط فقط.
- يفضّل تشغيلها على جهازك الشخصي أو خادم خاص موثوق. الواجهة مربوطة بـ `127.0.0.1` وليست منشورة على الإنترنت.

## الخطوات
1. انسخ `.env.local.example` إلى ملف باسم `.env` داخل هذا المجلد.
2. غيّر `POSTGRES_PASSWORD` و`OWNER_API_TOKEN` إلى قيم عشوائية قوية ومختلفة؛ اجعل رمز المالك 32 حرفًا على الأقل.
3. أدخل `LLM_API_KEY` و`LLM_MODEL`. لا تضع هذه القيم في GitHub.
4. من هذا المجلد شغّل: `docker compose up --build -d`.
5. افتح `http://127.0.0.1:8080` من المتصفح على نفس الجهاز.
6. أدخل رمز المالك، ثم اضغط «فحص الخادم». يجب أن يظهر أن الخادم وقاعدة البيانات متصلان.
7. جرّب طلبًا بسيطًا. نجاحه يعني إنشاء خطة محفوظة فقط، لا بناء التطبيق.

## إدارة الخدمة
- عرض السجلات: `docker compose logs -f api`
- إيقاف الخدمات: `docker compose down`
- إيقافها مع حذف بيانات قاعدة البيانات نهائيًا: `docker compose down -v` — لا تستخدم هذا الأمر إلا إذا أردت حذف بياناتك.

## تنبيهات
- `127.0.0.1` يعني نفس الجهاز الذي يشغّل Docker. إن فتحت الرابط من هاتف مختلف فلن يشير إلى حاسوبك. للوصول من الهاتف، شغّل الخدمات على الهاتف/Termux أو اضبط وصولًا خاصًا آمنًا على شبكتك؛ لا تفتح المنفذ مباشرة للإنترنت.
- يلزم إعداد مزود النموذج حتى تعمل الخطط. لا تضع المفتاح في واجهة GitHub Pages.
- ما زالت هذه النسخة لا ترفع الكتب، ولا تنشئ ملفات مشروع، ولا تشغّل اختبارات داخل sandbox، ولا تنشر تطبيقات أو APK.
