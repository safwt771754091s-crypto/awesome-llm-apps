# مركز وكلاء الذكاء الاصطناعي — Web + Android wrapper

واجهة عربية RTL ثابتة لاستعراض أمثلة من مستودع Awesome LLM Apps، وإدارة مهام محلية، وتجربة خط أنابيب من أربع مراحل عبر API متوافق مع OpenAI Chat Completions.

## ما يعمل في هذه النسخة
- واجهة متجاوبة للهاتف والحاسوب، مع قائمة مشاريع وروابط إلى المصدر.
- PWA وذاكرة تخزين مؤقت أساسية لواجهة المستخدم.
- سير عمل من أربع استدعاءات نموذج متتابعة (مخطط، محلل، مراجع، محرر نهائي).
- حفظ سجل المهام وتخصيص العرض وتصدير JSON في المتصفح.
- مشروع Android بسيط يعرض واجهة الويب في WebView.

## حدود مهمة
- هذه ليست عملية دمج أو تشغيل لكل المشاريع الموجودة في المستودع؛ لكل مثال تبعياته وخدماته الخاصة.
- لا توجد مصادقة حقيقية أو صلاحيات مالك آمنة من جهة الخادم. بيانات المالك والتاريخ في localStorage قابلة للتعديل من المستخدم.
- مفتاح API يُحفظ في sessionStorage ويُرسل من المتصفح؛ لا تستخدم مفتاحاً حساساً للإنتاج. لبناء منتج آمن، انقل استدعاءات النموذج إلى backend محمي بالمصادقة وحدود الاستخدام.
- يجب إعداد endpoint وAPI key من زر الإعدادات قبل تشغيل المختبر.
- اختبر إعداد CORS في مزود API؛ بعض المزودين يمنعون استدعاءات المتصفح.
- APK موقّع غير مضمّن؛ يلزم بناء Android وتوقيعه بإعدادات إصدار منفصلة.

## تشغيل الويب محلياً
يمكن فتح `index.html` للتصفح، لكن PWA وService Worker يتطلبان localhost أو HTTPS. من مجلد المستودع:
```bash
python -m http.server 8080
```
ثم افتح `http://localhost:8080/owner-agent-hub/`.

## بناء Android
افتح مجلد `android` في Android Studio أو نفّذ `gradle assembleDebug` بعد تثبيت JDK وAndroid SDK. التطبيق يفتح رابط GitHub Pages المضبوط في `app/build.gradle.kts`. لا تُدخل أسرار API في الشيفرة.

## النشر
يُجهّز workflow في `.github/workflows/agent-hub-pages.yml` لنشر مجلد `owner-agent-hub` إلى GitHub Pages عند دمج التغييرات إلى `main`. لن يصبح الموقع عاماً قبل دمج التغيير وتشغيل Workflow بنجاح، وتفعيل GitHub Pages إن لم يكن مفعلاً.
